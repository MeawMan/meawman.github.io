Shapefile fields:

Easting and Northing come from the point geometry. Each section's distance is measured along the best-fit line through its points; a section line (one polyline per CS, same ID) sets the left → right direction. Points without an ID can be assigned to the nearest section line.

Bank code selection:

Coordinates & Reach mapping (for Thalweg & Map)

Automatically tracks the lowest bed points to plot longitudinal thalweg profiles and 2D alignment maps.

2Rules & options

MSL → PWD in Bangladesh is typically +0.46 m. Section names in SOBEK become Prefix + ID. Separate several texts to remove with commas.

Bank crest trimming (optional — off by default)

Keeps only the main channel. "Ground drops" keeps rising bank up to the crest and cuts where the ground behind it falls more than the trim drop, so a floodplain level with the bank top is kept. "Bank codes" cuts exactly at the coded bank points. A side without a code always uses the crest rule. Spikes are ignored.
