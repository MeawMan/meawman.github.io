About River Profile Studio

River cross-sections, SOBEK Y-Z profiles & thalweg analysis

Open River Profile Studio

What it does

Convert surveyed river cross-section points (Excel / CSV) into SOBEK 2.1x Y-Z definitions (PROFILE.DEF). Interactively inspect and edit elevations and distances, add or delete specific survey points, select custom left and right bank codes for orientation, add vertical boundary walls, apply datum shifts (MSL to PWD), and merge into existing model files.

  • Interactive cross-section inspector: edit elevations (Z), distances (Y), add or delete points
  • Configurable bank code selection: assign left and right codes to enforce correct flow orientation
  • Vertical boundary walls: add custom wall height or extend to fixed flood level at beginning & end
  • SOBEK 2.1x integration: generate clean PROFILE.DEF or merge into existing case files in-place
  • Datum shift (e.g. +0.46 m MSL → PWD in Bangladesh) & optional bank crest trimming
  • Audit report: export comprehensive CSV summaries with widths, bed levels, and orientation status
  • Thalweg & Longitudinal Profiler: tracks the lowest bed points along the river, with a 2D plan map and 3D GeoJSON export

Problem

Convert surveyed river cross-sections into SOBEK CRDS ... lt yz definitions. Check and edit points visually, orient left bank first, add vertical walls, and export a clean PROFILE.DEF. Runs 100% in your browser.

Method

  • Cross-Section Inspector (Y-Z): interactively inspect and edit elevations and distances, add or delete specific survey points, select custom left and right bank codes for orientation.
  • Datum shift to Z (m): MSL → PWD in Bangladesh is typically +0.46 m. Section names in SOBEK become Prefix + ID.
  • Vertical wall at beginning & end: None (SOBEK standard extension); Add wall of size / height (+H m); Wall to fixed level (Z = … m).
  • Bank crest trimming (optional — off by default): keeps only the main channel between the natural bank crests.
  • Output: without a file, a clean new PROFILE.DEF is written. With an existing file, matching section names are updated in place.
  • Thalweg & Longitudinal Profiler (L-Profile): automatically tracks the lowest bed points to plot longitudinal thalweg profiles and 2D alignment maps. Shows Thalweg Bed Profile, Left Bank Crest, Right Bank Crest, Mean Bed Gradient (S₀) and an optional Water Surface; Reach Stations Checklist & Local Gradients; Export Thalweg CSV and Export 3D GeoJSON.

Data

Drop an Excel or CSV file (.xlsx · .xls · .csv · .txt) with Cross-section ID, Distance Y (m), Level Z (m) and an optional bank / data code; optional Easting / Longitude (X), Northing / Latitude (Y) and River / Reach / Khal name for the thalweg profile and map. 'Load sample survey' loads a built-in sample (9 sections in 2 reaches).
