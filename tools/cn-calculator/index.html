SCS Curve Number · TR-55 / NEH-4Composite CN Calculator

Paste your land use table straight from Excel into the sheet below. Each row is a sub-catchment; the area-weighted CN, AMC I/III values and design-storm runoff update as you paste or type.

1Parameters

Ia = λ·S · NEH-4 uses 0.20
Sets the CN used for S, Ia, Q
Event depth for the runoff check
Exclude if beels, ponds and ghers act as storage

2Input sheet Rows 1–3: sample from your workbook

Click a cell, then paste (Ctrl+V) a block copied from Excel. Data fills right and down from that cell, and rows are added as needed. If your block starts with a header row, columns are matched by name in any order. Areas in hectares. Soil accepts a texture (e.g. Clay Loam) or a group letter A–D. Move with Enter and arrow keys.

Equations
CN(II) = Σ(Aᵢ·CNᵢ) / ΣAᵢ (CNᵢ for the sub-catchment's soil group) CN(I) = 4.2·CN / (10 − 0.058·CN) CN(III) = 23·CN / (10 + 0.13·CN) S = 25400/CN − 254 (mm) Ia = λ·S Q = (P − Ia)² / (P − Ia + S) for P > Ia, else 0 C = Q/P V = Q·A·10 m³ (A in ha); with water excluded, A is the land area only
