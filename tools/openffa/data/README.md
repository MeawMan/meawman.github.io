# Sample data

Each file starts with `#` comment lines giving its source; the parser treats them as comments.

| File | Contents | Source and status |
|---|---|---|
| `usgs_01134500_moose_river_peaks.csv` | 68 annual peaks (ft³/s), water years 1947–2014 | Real. USGS (public domain), as printed in Bulletin 17C Table 10-2. Example 1: systematic record; regional skew 0.44, MSE 0.078 |
| `usgs_11274500_orestimba_creek_peaks.csv` | 82 annual peaks, 12 zero years | Real. Bulletin 17C Table 10-6. Example 2: low outliers (PeakFQ threshold 782 ft³/s) |
| `usgs_09480000_santa_cruz_river_peaks.csv` | 65 annual peaks 1949–2013 | Real. Bulletin 17C Table 10-22. Example 6: historic period 1927–1948 (22 years), threshold 12,000 ft³/s |
| `usgs_01134500_moose_river_daily.csv` | Daily mean discharge 1947–2014 | Real. USGS NWIS daily-values service, retrieved 2026-10-27 |
| `coles_port_pirie_sea_level.csv` | Annual max sea level, Port Pirie, 1923–1987 | Real. Coles (2001), via R package ismev |
| `coles_fremantle_sea_level.csv` | Annual max sea level and SOI, Fremantle | Real. Coles (2001), via ismev; shows a linear trend |
| `synthetic_monsoon_river_daily.csv` | 40 years of daily discharge (m³/s) | **Synthetic**, generated by `scripts/make_sample_data.py` (seed 1971) to imitate a monsoon river in Bangladesh. Includes a gauge outage in the 1994 monsoon. Not real data; do not cite as observations. |

No real Bangladeshi record is included: BWDB data are not openly licensed for redistribution. For the
paper's case study, use BWDB/FFWC data obtained under the agency's terms (see `docs/PAPER_OUTLINE.md`).

Regenerate the files with `python3 scripts/make_sample_data.py <usgs_daily.rdb>`. This needs R with ismev
for the Coles data.
