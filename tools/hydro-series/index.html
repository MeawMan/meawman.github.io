Fills the holes inside the record. The best estimate follows the seasonal pattern and the day-to-day memory of your series, anchored to the values on both sides of each hole. Real data is never changed.

Accuracy test

Hides parts of your real record that are known, fills them again with the model and compares with the truth. Shows how far to trust the filled values for holes of that length. It tests the sheet shown above.

Creates new years that behave like your record: the same seasonal pattern, spread, distribution and day-to-day memory. It continues from the last (or first) real value. These are plausible synthetic years, not forecasts.

What do these options mean?
Method
Statistical model builds new values from what it learned about your series (seasonal level and spread, distribution, day-to-day memory). Repeat real years copies whole real years, chosen at random for each new year: exact real values, but nothing new can appear.
Where
Adds the new period after the last date, or before the first date, of your record.
Set the range by
End year: the new period runs up to 31 December of that year (before the start: from 1 January of that year). Number of years: adds that many years.
Alternative series
How many different random versions to make. 1 gives one series. With more, every version is equally plausible, so you can test how much the answer depends on the random draw. They are on the "Series" menu and the "All series" sheet of the export.
Transform
How values are treated before learning. Auto uses a log scale for flow-like data (never negative, long upper tail, as in discharge) and no transform for levels. Generated flows never go below zero.
Random seed
A number that fixes the random draw. Same seed and same settings give the same result every time. Change it to get a different draw.
Stay within the real min and max
Stops any generated value from going above the highest or below the lowest real value.
Also fill the holes inside the record
Fills missing values inside your record first (best estimate), so the final series has no holes.
